# 📊 Marketing Campaign Performance Analysis Dashboard | Excel

## 🚀 Project Overview

This project focuses on analyzing digital marketing campaign performance using Microsoft Excel. The objective is to transform raw marketing data into meaningful business insights through data cleaning, KPI calculations, PivotTables, PivotCharts, and an interactive dashboard.

The dashboard provides a comprehensive overview of marketing performance by analyzing impressions, clicks, advertising costs, leads, digital sources, campaigns, and audience segments.

## 🎯 Project Objectives

- Analyze overall marketing campaign performance.
- Track impressions, clicks, leads, and advertising costs.
- Measure Cost Per Lead (CPL) and Click-Through Rate (CTR).
- Identify high-performing marketing campaigns.
- Compare digital marketing sources.
- Understand audience segment performance.
- Analyze lead generation and lead quality.
- Support data-driven marketing decisions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Excel Formulas and Functions
- Data Cleaning and Transformation
- PivotTables and PivotCharts
- Interactive Slicers
- KPI Development
- Data Visualization

## 📊 Dashboard Analysis

### 1. Leads by Campaign
Analyzes lead generation across different marketing campaigns to identify the best-performing campaigns.

### 2. Leads by Digital Source
Compares lead contributions from Paid Social, Paid Search, Direct Media, Programmatic, and other sources.

### 3. Leads by Audience
Evaluates audience segments such as Cloud Pros, Dev Pros, and Data Pros to understand their contribution to lead generation.

### 4. Cost Per Lead by Campaign
Compares campaign expenditure against generated leads to evaluate marketing cost efficiency.

### 5. Marketing Performance Analysis
Provides an overview of impressions, clicks, advertising costs, and leads.
